## 4. EDGE-TTS / VOICEOVER SPECIFICATION

**Provider:** edge-tts (Microsoft Azure)  
**Voice:** `en-US-AriaNeural` or `en-US-GuyNeural`  
**Rate:** 1.0x (standard speed; adjust to 0.95x if too fast, 1.05x if sluggish)  
**Pitch:** +5% (slightly elevated for perceived confidence)  

**Delivery Notes:**
- Emphasize keywords: "pattern," "smart money," "liquidations," "three possible outcomes"
- Pause 0.3s after complex statements (let them sink in)
- Drop vocal energy slightly for data sections, spike for CTAs
- No enthusiasm/enthusiasm dial is already baked into Aria—just clear delivery

**TTS Command (Python):**
```python
import edge_tts
import asyncio

async def generate_crypto_voiceover():
    text = "[Full script above]"
    communicate = edge_tts.Communicate(
        text,
        voice="en-US-AriaNeural",
        rate="+0%",
        pitch="+5Hz"
    )
    await communicate.save("crypto_voiceover.mp3")

asyncio.run(generate_crypto_voiceover())
```

## 9. JARVIS1 PIPELINE INTEGRATION

### Stage 2 → Stage 3 Flow:

**Input (Stage 2 Complete):**
- Video script (above)
- TTS audio file (edge-tts output)
- Scene breakdown (table above)

**Processing (Stage 3):**
```
1. Parse B-roll keywords from each scene
2. Query Pexels/Pixabay API for matching stock footage
   - For TradingView charts: Use screenshot + overlay graphics
   - For animated elements: Render custom MP4s or pull from motion library
3. Assemble timeline:
   - Scene 1 (3s): Hook graphic + candle animation
   - Scene 2 (27s): TradingView chart screen recording
   - Scene 3 (retention): Indicator flash graphic
   - [Continue for each scene]
4. Sync TTS audio to timeline
5. Add background music (BPM-matched to scene)
6. Render final MP4 at 1080p/60fps
7. Generate thumbnail (title + chart graphic)
8. Output: crypto_btc_analysis_YYYYMMDD.mp4 + thumbnail.png
```

**JARVIS Config Addition:**
```python
# skills/youtube_automation/crypto_generator.py
CRYPTO_SCENE_TEMPLATES = {
    "hook": {"duration": 3, "music_bpm": 130, "voice_tone": "intense"},
    "market_setup": {"duration": 27, "music_bpm": 115, "voice_tone": "analytical"},
    "data_breakdown": {"duration": 120, "music_bpm": 110, "voice_tone": "expert"},
    "strategy": {"duration": 105, "music_bpm": 125, "voice_tone": "confident"},
    "cta": {"duration": 43, "music_bpm": 140, "voice_tone": "motivational"},
}

def generate_crypto_video(angle: str = "bearish") -> str:
    """Generate crypto analysis video with specified angle"""
    script = get_script_variant(angle)
    audio = generate_tts(script, voice="aria", rate=1.0)
    scenes = render_scenes(CRYPTO_SCENE_TEMPLATES, audio)
    video = assemble_video(scenes)
    thumbnail = generate_thumbnail(angle)
    return upload_to_youtube(video, thumbnail, metadata=SEO_DATA[angle])
```
